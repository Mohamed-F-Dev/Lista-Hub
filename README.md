## 🧾 About

> **A multi-city platform connecting people with local businesses, services, offers, and community opportunities — all in one place.**

**Lista Hub** makes it easy to discover local services and businesses while giving merchants the tools to manage their stores, services, offers, and ads. It also brings community buying, selling, and job opportunities together in a single platform.

---

## ⚙️ How It Works

Describe the core app flow:

```
Open App → Set Location & City → Explore → Sign Up When Needed → Take Action 
```
1. **Auth:** Location & City: Users set their city and location to discover relevant local businesses,   
1. **Location & City:** Set your city and location to discover nearby content.
2. **Explore:** Browse businesses, services, offers, and community posts freely.
3. **Authentication:** Create an account only when an action requires it.
4. **Core Loop:** Discover, explore, interact, buy, sell, or find local opportunities.
5. **Merchant Dashboard:** Manage your store, services, offers, and advertisements.
6. **Notifications:** Receive updates about posts, offers, and platform activity.

---

## 💼 Real-World Use Cases

- **Daily Users:** Discover nearby businesses, services, offers, and local opportunities.

- **Community Members:** Buy, sell, request services, and share opportunities within their city.

- **Business Owners:** Create and manage stores, services, offers, and advertisements from one dashboard.

## ✨ Features

- Discover nearby businesses, services, and offers
- Location-based services and places
- Smart search and filtering with debounce
- Real-time data synchronization
- Offline support with local data caching
- Paginated data loading for better performance
- Push notifications with Firebase Cloud Messaging
- In-app chat with Crisp
- Arabic and English localization
- Deep linking for direct content access
- Responsive design across different screens
- Image optimization and caching
- Secure authentication with Firebase
- Admin Dashboard for platform management
- Performance optimization and error handling
